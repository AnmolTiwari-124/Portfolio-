NestMate

Roommate-matching platform

NestMate helps people find compatible roommates. It is built for matching people, not for listing rooms or PGs. Members set up a profile and preferences, discover people near them, and talk in real time.

  • JWT authentication with bcrypt-hashed passwords
  • Profile and preference management
  • Rule-based compatibility scoring
  • Search and filtering
  • Location-based roommate discovery
  • Bookmarking of profiles
  • Real-time chat with Socket.IO
